# Macro

A simple application for creating custom text shortcuts.

Type a command such as `.wpp` into any text field, and Macro will automatically replace it with the configured content.

## Features

- Create and edit macros
- Global keyboard detection
- Automatic text replacement
- Shortcut to enable or disable the system
- Runs in the background
- Windows system tray icon
- Automatic macro saving

## How to Use

1. Download `Macro.exe` from the Releases page.
2. Open the application.
3. Create a new macro.
4. Set a shortcut, for example:

```text
.wpp
```

5. Set the replacement content:

```text
Contact me on WhatsApp: (xx) xxxxx-xxxx
```

That's it. Whenever `.wpp` is typed, the text will be replaced automatically.
